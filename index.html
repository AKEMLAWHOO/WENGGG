About Me

My name is Samuel Andrei P. Dimla and I'm a college student taking Computer Fundamentals. Before this class I mostly used computers, I never really thought about how the things on the screen were made. Now I do, and I find it a lot more interesting than I expected.

I'm the type of person who likes to take their time and get things right. If I don't understand something, I keep going at it until I do, and I'm happy to ask for help or explain things to classmates when they're stuck.

The design system part of this project was the hardest for me. It took a while to get the colors and font sizes to match, but I learned a lot about how much detail goes into making a website look consistent.

What I can do so far

  • Write basic HTML and CSS
  • Use semantic tags to structure a page
  • Read a color palette and type scale and recreate it in code
  • Use Figma to look at design files
  • Troubleshoot common computer problems

Still learning

  • JavaScript

  • Git and GitHub

Career Aspirations

I want to work in the tech industry as a web developer, and later on I'd like to move into UI/UX design. What I like most is that you can write some code and see the result on the screen right away. Seeing a blank page turn into something that looks right is a good feeling.

Working on the design systems showed me that good design is not just about looking nice. HubSpot and National Geographic look nothing alike, but both are very consistent, and that consistency makes them easy to use. I'd like to be the person who makes that kind of thing.

In the long run I hope to work on products that actually help people, like apps for schools or small local businesses. My plan is:

  1. Finish my degree and get good at HTML, CSS and JavaScript.
  2. Build more projects of my own so I have real work to show.
  3. Get an internship or a junior developer job.
  4. Keep learning, and grow into front-end or UI/UX work.
